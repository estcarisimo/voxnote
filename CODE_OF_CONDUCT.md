# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful, assume good faith, and keep discussions about the work.
Harassment, personal attacks and discrimination of any kind are not tolerated.

Report unacceptable behavior privately to the maintainer at
<estcarisimo@gmail.com>. Reports are handled confidentially.
